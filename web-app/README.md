# Nexus (web-app)

This is the Next.js application. For install instructions and the full repo
layout (including `voicechanger/` and `local_data/`), see the root
[`README.md`](../README.md) one level up.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

See `scripts/README.md` for notes on folder-naming independence and what
the installer does not automate yet (TTS engines, recognize.exe).
